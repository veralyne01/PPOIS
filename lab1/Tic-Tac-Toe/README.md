# Tic-Tac-Toe

Консольная игра «Крестики-нолики», реализованная на C#.

## О проекте

Проект разработан в рамках лабораторных работ по дисциплине
«Проектирование программного обеспечения информационных систем» (ППОИС).
Игра рассчитана на двух игроков, которые по очереди делают ходы на поле
размером 3 × 3.

## Возможности

-   Игра для двух игроков: X и O.
-   Ввод номера строки и столбца для выбора клетки.
-   Проверка корректности введённых координат.
-   Проверка занятости выбранной клетки.
-   Определение победителя по горизонтали, вертикали или диагонали.
-   Определение ничьей, если все клетки заняты и победителя нет.
-   Повторный запрос ввода при некорректных данных.

## Реализация

Игровая логика разделена на несколько классов:

-   **`Game`** --- управляет ходом игры, переключает игроков, выполняет
    ходы и проверяет победу или ничью.
-   **`Player`** --- хранит знак игрока (`X` или `O`) и состояние
    занятых клеток.
-   **`InputValidator`** --- проверяет введённые координаты и
    доступность выбранной клетки, а также повторяет запрос при
    некорректном вводе.
-   **`Start`** --- содержит точку входа в приложение и запускает новую
    игру.

### Представление игрового поля

Состояние поля хранится с помощью битовых масок. Каждой клетке
соответствует один бит целого числа. Для фиксации хода используется
побитовая операция `OR`, а для проверки занятости клетки и выигрышных
комбинаций --- побитовые операции `AND`.

Выигрышные комбинации заданы заранее в виде битовых масок для трёх
строк, трёх столбцов и двух диагоналей.

## Технологии

-   C#
-   .NET
-   Побитовые операции для представления игрового поля

## Запуск

1.  Откройте решение проекта в Visual Studio.
2.  Выберите проект Tic-Tac-Toe в качестве запускаемого.
3.  Запустите приложение.
4.  Введите номер строки и столбца от `0` до `2`, чтобы выбрать клетку.

Например, значения `0` и `2` обозначают клетку в первой строке и третьем
столбце.

## Тестирование

В проекте предусмотрена возможность доступа тестовой сборки к внутренним
типам через атрибут `InternalsVisibleTo("Tests")`.

Если тестовый проект добавлен в решение, тесты можно запускать через
**Test → Run All Tests** в Visual Studio или командой `dotnet test` из
каталога решения.

## Примечание

Номера строк и столбцов вводятся начиная с нуля: допустимый диапазон для
каждого значения --- от `0` до `2`.
