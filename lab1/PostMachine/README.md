# Post Machine

Консольное приложение на C#, имитирующее работу машины Поста ---
абстрактной вычислительной модели с лентой, ячейками и подвижным
кареточным механизмом.

## О проекте

Программа позволяет вручную управлять лентой машины Поста с помощью меню
команд. Пользователь может устанавливать и удалять метки, перемещать
каретку, проверять состояние текущей ячейки и очищать ленту.

## Возможности

-   Установка метки в текущей ячейке.
-   Удаление метки из текущей ячейки.
-   Перемещение каретки влево на заданное количество ячеек.
-   Перемещение каретки вправо на заданное количество ячеек.
-   Проверка, установлена ли метка в текущей ячейке.
-   Очистка ленты и возврат каретки в начальную позицию.
-   Проверка пользовательского ввода на корректность целого
    неотрицательного числа.

## Команды меню

  Команда   Действие
  --------- -----------------------------------------------------
  `1`       Установить метку в текущей ячейке
  `2`       Удалить метку из текущей ячейки
  `3`       Переместить каретку влево на указанное число ячеек
  `4`       Переместить каретку вправо на указанное число ячеек
  `5`       Очистить ленту и вернуть каретку в позицию `0`
  `6`       Проверить, содержит ли текущая ячейка метку
  `7`       Завершить работу программы

## Структура проекта

-   **`Slider`** --- хранит позицию каретки и множество ячеек с метками.
    Реализует операции установки и удаления меток, перемещения, проверки
    ячейки и сброса состояния.
-   **`InputValidator`** --- считывает ввод пользователя и проверяет,
    что введено целое неотрицательное число.
-   **`Program`** --- отображает меню, обрабатывает выбранные команды и
    вызывает методы класса `Slider`.

## Реализация ленты

Позиция каретки хранится в целочисленной переменной. Ячейки с
установленными метками хранятся в `HashSet<int>`, где число обозначает
позицию ячейки.

Такое представление позволяет быстро проверять наличие метки в
конкретной ячейке. Ячейки без меток отдельно не хранятся.

## Технологии

-   C#
-   .NET
-   `HashSet<int>` для хранения позиций ячеек с метками

## Запуск

1.  Откройте решение проекта в Visual Studio.
2.  Выберите проект `PostMachine` в качестве запускаемого.
3.  Запустите приложение.
4.  Следуйте инструкциям меню в консоли.

Для команд перемещения введите неотрицательное целое число ---
количество ячеек, на которое нужно переместить каретку.

## Ограничения текущей реализации

-   Проверяется формат ввода и то, что введённое число неотрицательное.
-   Ввод отрицательного числа для перемещения не поддерживается: для
    движения в противоположную сторону используйте соответствующую
    команду меню.
-   Программа имитирует операции с лентой и кареткой, но не выполняет
    произвольную программу машины Поста из набора команд.
